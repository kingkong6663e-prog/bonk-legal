B 0 N K — Privacy Policy

Last updated: October 4, 2026

B 0 N K ("the Bot", "we", "us", or "our") is a Discord bot designed for Albion Online guilds and communities.

1. Information We Collect

B 0 N K may store information necessary to provide its features, including Discord user IDs, Discord server IDs, Discord server configuration, Albion Online character information provided through the Bot, recruitment/application information, event participation information, and premium subscription or entitlement information.

2. How We Use Information

Information is used to operate B 0 N K and provide features such as recruitment management, events and attendance, regear management, giveaways, Albion-related tools, server configuration, and premium access management.

3. Patreon and Payments

Premium memberships and purchases may be processed through Patreon. Payment information is handled by Patreon and is not stored directly by B 0 N K.

B 0 N K may receive limited information from Patreon that is necessary to verify a user's premium membership or purchase.

4. Discord

B 0 N K operates through Discord and may process information made available through Discord's API and interactions with the Bot. Discord's own privacy policy also applies to information processed by Discord.

5. Data Storage

We retain information only for as long as reasonably necessary to provide B 0 N K's features, maintain records, prevent abuse, and manage premium access.

6. Data Sharing

We do not sell users' personal information. Information may be processed by third-party services when necessary to operate B 0 N K, including Discord, Patreon, hosting providers, and relevant API providers.

7. Data Deletion

Users or server administrators may request deletion of information associated with B 0 N K where applicable. Requests can be made by contacting the B 0 N K administrator through the official Discord support channel or other official contact method provided by B 0 N K.

8. Security

We take reasonable measures to protect information used by B 0 N K. However, no online service can guarantee absolute security.

9. Changes to This Policy

This Privacy Policy may be updated as B 0 N K develops new features or changes its services. The updated version will be published on this page.

10. Contact

For privacy questions or data-related requests, contact the B 0 N K administrator through the official B 0 N K support channels.
